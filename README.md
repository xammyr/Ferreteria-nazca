# Ferretería Nazca 🛠️

Servicio de tienda web para una ferretería local en la región de Nazca, diseñado para optimizar las ventas y gestión de inventario.

## Características Principales
1. Catálogo interactivo de productos.
2. Carrito de compras con proceso de confirmación y pago por Yape.
3. Panel backend (API) para inventario, ventas y gestión con Prisma (MySQL).
